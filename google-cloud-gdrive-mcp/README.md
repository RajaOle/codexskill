# Google Cloud Google Drive MCP

Portable OpenClaw MCP server for Google Drive and Google Sheets. This folder is safe to sync through GitHub because it contains only source code, package metadata, and setup instructions.

## Tools

- `auth_status`: verify OAuth credentials and token.
- `list_files`: list or search Google Drive files.
- `read_sheet`: read all tabs from a Google Sheet.
- `read_sheet_range`: read one Sheet range.
- `read_sheet_formula_range`: read formulas from one Sheet range.
- `write_sheet`: update or append Sheet values.
- `duplicate_sheet`: duplicate a tab while preserving formatting and formulas.
- `upload_file`: upload a local file and create an anyone-with-link reader permission.
- `get_folder_id`: find Drive folder IDs by name.

## Credentials

Do not commit Google credentials or tokens.

Required local files on each machine:

- `GDRIVE_CREDENTIALS_PATH`: Google Cloud OAuth client JSON.
- `GDRIVE_TOKEN_PATH`: OAuth token JSON generated by `npm run auth`.

Recommended VPS layout:

```bash
mkdir -p /home/openclaw/.openclaw/secrets
chmod 700 /home/openclaw/.openclaw/secrets
```

Place credentials outside the repo:

```bash
/home/openclaw/.openclaw/secrets/gdrive-credentials.json
/home/openclaw/.openclaw/secrets/gdrive-token.json
```

Use permissions:

```bash
chmod 600 /home/openclaw/.openclaw/secrets/gdrive-credentials.json
chmod 600 /home/openclaw/.openclaw/secrets/gdrive-token.json
```

If you want the VPS to use the same Google account authorization as the MiniPC, copy only these two secret JSON files over SSH or another private channel. Do not put them in GitHub. If you want separate VPS auth, copy only the OAuth client JSON and run `npm run auth` on the VPS to generate a new token.

## Install

```bash
cd /home/openclaw/codexskill/google-cloud-gdrive-mcp
npm ci
```

## Generate Token

```bash
export GDRIVE_CREDENTIALS_PATH=/home/openclaw/.openclaw/secrets/gdrive-credentials.json
export GDRIVE_TOKEN_PATH=/home/openclaw/.openclaw/secrets/gdrive-token.json
npm run auth
```

## OpenClaw MCP Config

Add or update the MCP server entry on the VPS:

```toml
[mcp_servers.gdrive]
command = "node"
args = ["/home/openclaw/codexskill/google-cloud-gdrive-mcp/index.js"]
env = { GDRIVE_CREDENTIALS_PATH = "/home/openclaw/.openclaw/secrets/gdrive-credentials.json", GDRIVE_TOKEN_PATH = "/home/openclaw/.openclaw/secrets/gdrive-token.json" }
```

Use the actual OpenClaw user home if it is not `/home/openclaw`.

## Health Check

```bash
export GDRIVE_CREDENTIALS_PATH=/home/openclaw/.openclaw/secrets/gdrive-credentials.json
export GDRIVE_TOKEN_PATH=/home/openclaw/.openclaw/secrets/gdrive-token.json
npm run refresh-token
```

For production, run this as a periodic systemd timer or before restarting OpenClaw to catch revoked tokens early.
