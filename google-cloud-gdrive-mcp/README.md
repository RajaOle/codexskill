# Google Cloud Google Drive MCP

Portable OpenClaw MCP server for Google Drive and Google Sheets. This folder is safe to sync through GitHub because it contains only source code, package metadata, and setup instructions.

## Tools

- `auth_status`: verify OAuth credentials and token.
- `list_files`: list or search Google Drive files.
- `read_sheet`: read all tabs from a Google Sheet.
- `read_sheet_range`: read one Sheet range.
- `read_sheet_formula_range`: read formulas from one Sheet range.
- `write_sheet`: update or append Sheet values.
- `duplicate_sheet`: duplicate a tab while preserving formatting and formulas.
- `upload_file`: upload a local file and create an anyone-with-link reader permission.
- `get_folder_id`: find Drive folder IDs by name.

## Credentials

Do not commit Google credentials or tokens.

Required local files on each machine:

- `GDRIVE_CREDENTIALS_PATH`: Google Cloud OAuth client JSON.
- `GDRIVE_TOKEN_PATH`: OAuth token JSON generated by `npm run auth`.

Recommended VPS layout:

```bash
mkdir -p /home/openclaw/.openclaw/secrets
chmod 700 /home/openclaw/.openclaw/secrets
```

Place credentials outside the repo:

```bash
/home/openclaw/.openclaw/secrets/gdrive-credentials.json
/home/openclaw/.openclaw/secrets/gdrive-token.json
```

Use permissions:

```bash
chmod 600 /home/openclaw/.openclaw/secrets/gdrive-credentials.json
chmod 600 /home/openclaw/.openclaw/secrets/gdrive-token.json
```

If you want the VPS to use the same Google account authorization as the MiniPC, copy only these two secret JSON files over SSH or another private channel. Do not put them in GitHub. If you want separate VPS auth, copy only the OAuth client JSON and run `npm run auth` on the VPS to generate a new token.

## Install

```bash
cd /home/openclaw/codexskill/google-cloud-gdrive-mcp
npm ci
```

## Generate Token

```bash
export GDRIVE_CREDENTIALS_PATH=/home/openclaw/.openclaw/secrets/gdrive-credentials.json
export GDRIVE_TOKEN_PATH=/home/openclaw/.openclaw/secrets/gdrive-token.json
npm run auth
```

## OpenClaw MCP Config

Add or update the MCP server entry on the VPS:

```toml
[mcp_servers.gdrive]
command = "node"
args = ["/home/openclaw/codexskill/google-cloud-gdrive-mcp/index.js"]
env = { GDRIVE_CREDENTIALS_PATH = "/home/openclaw/.openclaw/secrets/gdrive-credentials.json", GDRIVE_TOKEN_PATH = "/home/openclaw/.openclaw/secrets/gdrive-token.json" }
```

Use the actual OpenClaw user home if it is not `/home/openclaw`.

## Health Check

```bash
export GDRIVE_CREDENTIALS_PATH=/home/openclaw/.openclaw/secrets/gdrive-credentials.json
export GDRIVE_TOKEN_PATH=/home/openclaw/.openclaw/secrets/gdrive-token.json
npm run refresh-token
```

For production, run this as a periodic systemd timer or before restarting OpenClaw to catch revoked tokens early.

## Mili tables and documents (2026-10-13)

`inspect_table` automatically discovers live headers; no manual table registration. `initialize_table` creates a new tab or initializes an entirely blank/unformatted tab once. Existing template/header values, formatting and formulas stay protected. `write_table_records` accepts exact-header-keyed objects, maps fields and selects rows, supports idempotent insert/upsert, checks dropdowns/concurrent edits and verifies results. Original references and dedicated expense ledgers retain their guards. Newly created workbooks are protected automatically. Raw mutation/file replacement routes cannot bypass protection.

Public backup redacts live workbook IDs. Set `MILI_TEMPLATE_ID`, `MILI_TRACKER_ID`, `MILI_SINDY_ID`, `MILI_IBNU_ID` to actual local workbook IDs before deployment. Keep `GDRIVE_TABLE_STATE_PATH` outside the repository (default: installed private gdrive directory); never publish snapshots or runtime state. Install the paired `openclaw-local-plugins/mili-attachments` reader and set `MILI_DOCUMENT_READER` to its absolute index.js path when using a different home/layout.

`read_document` extracts exact Drive PDFs/images, Office/OpenDocument and text locally. `read_file(content=true)` automatically extracts supported Office documents. Reader requires Python 3, file, Poppler/Tesseract and LibreOffice for legacy DOC/XLS/PPT/RTF. DOCX/XLSX/PPTX/OpenDocument need no additional Python packages. Embedded Office images are not OCRed directly; spreadsheet formula values are cached, not recalculated. Chunks expose page/character continuation. Macros are not executed.

Run `node table-tools.test.js`, `node tracker-guard.test.js`, `node expense-guard.test.js`, `node crud.test.js`. Use the paired reader tests for extraction/OCR. No live delivery tests.

## Safe human header changes (2026-10-14)

`inspect_table` can adopt additive human changes to operational headers after two identical live reads. All existing fields remain in order; an empty combined Phone / Email column may become adjacent Phone and Email fields. Prior snapshots remain in private state revisions. No Sheet values, formatting, validation or formulas change during discovery. Data writes require fresh inspection after schema changes and use the current exact header names. Removed/renamed/reordered fields, changed title/instruction rows, populated contact splits, legacy supplier/price schemas and accounting/reference templates remain blocked. Mixed contact fields accept phone or email; dedicated columns retain strict typing.
